## What changed

The Contoso Coffee demo data tool (`CreateNoSeries`) inserts one more number series on 29.1: the series for Spend
Requests, starting at `10001`. Spend Requests are new in the 29.1 Base Application.

| Version | No. Series rows (table 308) in the demo company |
|---|---|
| 29.0 | 119 |
| 29.1 | 120 |

In the same run, the number of Job Queue Entry rows in the company "My Company" went from 1 to 2. Where that entry
comes from is not known yet, so it is not part of this entry.

## Who is affected

Tests that count all number series of the demo company, or that pick a number series by position.

## Microsoft documentation

Not found. KB 5135161 lists a Contoso change about the default currency display setting, not the number series.
