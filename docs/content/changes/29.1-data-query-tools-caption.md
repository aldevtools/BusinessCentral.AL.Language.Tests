## What changed

In the System Application, enum "MCP Server Feature" (`MCPServerFeature.Enum.al`):

| Version | Caption of value 2 "Data Query Tools" |
|---|---|
| 29.0 | `Data Query Tools (Preview)` |
| 29.1 | `Data Query Tools (Preview/Billable)` |

The enum value name and ordinal did not change. 29.1 also adds a billing confirmation page that opens when the feature
is turned on. The corpus does not measure that page yet.

The MCP server features do not exist in 27 and 28, so there is nothing to compare there.

## Who is affected

Code or tests that compare the caption (`Format` of the enum value) instead of the value or its ordinal.

## Microsoft documentation

Yes. [KB 5135161](https://support.microsoft.com/help/5135161), application hotfix 653341: "Prepares MCP data query
tools for billing." It does not name the caption.
