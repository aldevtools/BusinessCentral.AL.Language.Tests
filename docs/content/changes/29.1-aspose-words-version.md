## What changed

Business Central converts Word layouts to Html with Aspose.Words, for example for an e-mail body
(`Report.SaveAs` with `ReportFormat::Html` on a Word layout). Aspose.Words writes its version into the Html as a
`generator` meta tag.

| Version | Aspose.Words | Effect on the Html |
|---|---|---|
| 27.5, 28.5 | 26.10.0 | baseline |
| 29.0 | 26.8.0 | one character shorter, different SHA-256 |
| 29.1 | 26.10.0 | the same length as on 27.5 and 28.5 |

The 29.1 version was read from `Aspose.Words.dll` of the 29.1 service tier. The 29.0 version comes from the probe's
observation on build 29.0.54011.55816. The probe asserts the character count and the SHA-256 of the Html. On 29.1 the
character count matches 27.5 and 28.5; the hashes on 29.1 were not reported separately yet.

## Who is affected

Tests or code that compare the exact bytes, length or hash of Html made from a Word layout. Compare the text content
instead, or remove the `generator` meta tag before you compare.
