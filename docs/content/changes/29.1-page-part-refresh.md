## The code

A host page (Worksheet or List) has a FactBox part. The part has a procedure that fills a temporary table. The host
calls that procedure from OnOpenPage, OnAfterGetCurrRecord and an action. A TestPage opens the host with `OpenView`,
moves with `GoToRecord`, invokes the action and then calls `Next`.

## What changed

On 29.0, for a part over a temporary table:

- After the action, the part read its rows a third time. The log ends with one more
  `OnAfterGetRecord, OnAfterGetRecord, OnAfterGetCurrRecord` sequence of the part.
- After `Next`, the part ran OnAfterGetCurrRecord on its empty rows.

On 29.1 neither happens. The trigger sequence is the same as on 27 and 28.

A part over a stored table that the procedure filters with `SetRange` gives the 27/28 sequence on all versions,
including 29.0.

## Who is affected

Code that counts or depends on part trigger calls after an action, for example a part that fills a buffer in
OnAfterGetCurrRecord. Tests written on 29.0 that assert the extra trigger calls fail on 29.1.
